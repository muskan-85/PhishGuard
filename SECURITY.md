# Security Policy

## Project Status

PhishGuard is an academic project developed for educational and demonstration purposes.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately to the repository owner through GitHub.

Please avoid publicly sharing sensitive vulnerability details before the issue has been reviewed.

## Scope

This project analyses submitted URL text for phishing indicators. It does not visit or open submitted URLs.

## Disclaimer

PhishGuard is an academic prototype and is not a replacement for professional cybersecurity tools or security practices.
